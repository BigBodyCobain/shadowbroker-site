// trust model

        
No accounts. No analytics. No product telemetry.

        
The dashboard's API calls go only to your self-hosted backend, and operator keys stay in your deployment. Sensitive recon and Shodan queries are proxied server-side behind SSRF guards and local-operator auth — never sent from the browser to third-party APIs.

        
As the README notes, live OSINT layers still fetch from the public data providers you enable (map tiles, imagery, camera streams).

// 04 — deploy

        
Operational in one command.

        
Pick your OS, paste one line into a terminal. It clones the repo, pulls the pre-built signed images and opens the dashboard at localhost:3000. Needs Git and Docker running (Docker Desktop on macOS / Windows; the backend wants ~4 GB RAM). The first pull takes a few minutes — if the browser opens before the dashboard is up, refresh after a minute.

        

          
API keys — two free sign-ups unlock everything

          
    
            
  • Ships (AIS) — required for the vessel layer: free key at aisstream.io → AIS_API_KEY
    • 
            
  • Global flights — free OpenSky OAuth login → OPENSKY_CLIENT_ID / OPENSKY_CLIENT_SECRET
    • 
            
  • Optional — your own SHODAN_API_KEY for the device-search overlay
    • 
          

          
Put them in a .env file in the Shadowbroker folder, then run docker compose up -d again. Settings → API Keys in the dashboard shows what's configured. Most other layers work with no keys at all.

// 07 — faq

        
Questions, answered.

      

      

        

          Is ShadowBroker free?
          
Yes. ShadowBroker is open-source software under the AGPL-3.0 licence. You run it yourself with Docker, so there is no subscription and nothing to pay for the software. A few optional data sources (such as Shodan) need your own key from that provider.

        

        

          Do I need an account?
          
No. ShadowBroker has no accounts, no product telemetry and no analytics. The dashboard talks only to the backend you host yourself. Live layers do make outbound requests to the public data providers you turn on.

        

        

          What data does it show?
          
60+ live public feeds across 40+ map layers: aircraft (ADS-B), ships (AIS), satellites, earthquakes, volcanoes and wildfires (NASA FIRMS), GPS jamming, CCTV cameras, KiwiSDR radio, Meshtastic and APRS mesh radio, trains, power plants and data centres, Telegram OSINT channels, and cyber threat feeds such as CISA KEV.

        

        

          How do I install it?
          
You need Git and Docker running (Docker Desktop on macOS and Windows; the backend wants about 4 GB of RAM). Paste the one-line command for your OS from the deploy section: it clones the repo, pulls the pre-built images and opens the dashboard at localhost:3000.

        

        

          Which API keys do I need?
          
Most layers work with no keys at all. Two free sign-ups unlock the rest: an aisstream.io key for ships (AIS_API_KEY) and an OpenSky login for global flights (OPENSKY_CLIENT_ID and OPENSKY_CLIENT_SECRET). Shodan is optional and uses your own key.

        

        

          Is this a surveillance tool?
          
It does not create new surveillance capabilities. ShadowBroker brings together datasets that are already public, such as aircraft and ship transponder broadcasts, satellite orbits and earthquake sensors, and shows them on one map. The code is fully open source, so anyone can audit what data it accesses and how.

        

        

          Can I connect an AI agent?
          
Yes. ShadowBroker has an HMAC-signed agent command channel that works with OpenClaw and any agent that speaks the protocol, including Claude- and GPT-based agents. The agent can search telemetry and news across all layers, run recon lookups, place pins and control the map.

        

        

          What is $SB?
          
$SB is the ShadowBroker community token on Solana, launched on pump.fun. The software itself is free and does not require the token.
